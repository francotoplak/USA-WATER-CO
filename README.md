# Door Log

Mobile web app for USA Water Co door-to-door reps. Open it on a phone, tap a house on the map, and log the visit as Not home, Not interested, Interested or Booked. Bookings can be added to Google Calendar (with the owner invited) or downloaded as an .ics file.

- Single static page: `index.html` (Leaflet map, OpenStreetMap / Esri satellite tiles, browser location). Tabs: Map, Days (activity per day), Doors (search and filter), Settings.
- Doors are saved on each phone (browser storage). Use **Export all doors (CSV)** in the list view to share them.
- Hosted with GitHub Pages from the `main` branch.
